# 화면 용어를 문어체로 정리하기

## 배경
화면의 라벨이 "내가 이어받을 일", "막힌 이유", "원래 요건"처럼 말하듯이 풀어 쓴 표현이면 길고, 화면마다 표현이 달라지기 쉽다. 일본어 업무 문서는 말할 때 쓰는 표현(話し言葉)과 글에 쓰는 표현(書き言葉)을 엄격히 나누고, 항목 이름은 한자어 명사로 끝맺는다(体言止め). 그 방식을 한국어에 적용해 라벨은 짧은 한자어 명사로, 안내 문장은 정중한 평서문으로 맞춘다. 일본어 낱말을 가져오는 것이 아니라 구분하는 방식만 참고한다.

## 원칙
1. **라벨과 문장을 나눠서 다룬다.**
   - 라벨(메뉴, 화면 제목, 구역 제목, 버튼, 상태 표시, 표 머리, 입력 칸 이름): 명사로 끝낸다.
   - 문장(오류, 안내, 빈 화면 설명, 확인 문구): "~습니다"체를 유지한다. 라벨처럼 줄이지 않는다.
2. **풀어 쓴 말을 한자어 명사로 바꾼다.**
   - "~한 이유" → 사유 / "~할 일" → 조치, 업무 / "~하기를 기다림" → 대기
   - "~한 것들" → 내역, 목록 / "~하는 중" → 진행 / "아직 안 함" → 미실시, 미확인
   - 원래 → 상위, 기존 / 지금 → 현재, 현행 / 예전 → 종전 / 다시 → 재(재시도, 재조회)
   - 넘기다 → 인계 / 고르다 → 선택 / 바꾸다 → 변경 / 되돌려 보내다 → 반려 / 남 → 제3자
3. **한 낱말에 한 뜻만 둔다.** 같은 개념은 모든 화면에서 같은 이름으로 부르고, 한 화면에서 같은 낱말이 두 가지 뜻으로 쓰이지 않게 한다.
4. **너무 딱딱하거나 낯선 말은 쓰지 않는다.** 사용자가 평소 업무 문서에서 보는 낱말만 쓴다. 특정 조직에서만 쓰는 결재 용어, 일본식 한자어 직역은 피한다.
5. **바꾸면 더 길어지거나 뜻이 흐려지는 것은 그대로 둔다.** 버튼과 상태 표시는 2~6자를 목표로 한다.
6. **건드리지 않는 것**: 제품 이름, 사용자가 이미 정한 용어, 사용자가 입력한 내용(데이터), 코드의 변수·키 이름.

## 진행 순서
1. 화면에 나오는 문자열을 모두 모은다(화면 코드, 서버가 돌려주는 메시지, 예시 데이터의 라벨).
2. 용어표를 만든다: 지금 표현 / 바꿀 표현 / 이유. 같은 개념이 여러 이름으로 불리는 곳을 함께 표시한다.
3. 확신이 낮은 것만 사용자에게 묻고, 나머지는 바로 적용한다. 사용자가 이미 정한 용어를 바꾸는 제안은 반드시 묻는다.
4. 일괄로 바꾼 뒤 반드시 점검한다.
   - **조사**: 낱말이 바뀌면 을/를, 이/가, 은/는, 과/와, 로/으로가 틀어진다(예: "다음 할 일을" → "다음 조치을"). 바꾼 낱말 뒤의 조사를 전부 다시 확인한다.
   - **변수 뒤 조사**: "‘${값}’로"처럼 값에 따라 달라지는 곳은 받침에 맞춰 붙게 한다. 받침이 없거나 ㄹ 받침이면 "로", 그 밖의 받침이면 "으로".
   - "(으)로", "이(가)" 같은 괄호 표기가 남아 있으면 고친다.
   - 남은 구어체가 없는지 다시 검색한다.
   - 시험 코드나 다른 코드가 바뀐 문자열을 참조하면 함께 고친다.
5. 실제 화면을 띄워 글자가 잘리거나 줄이 넘어가는 곳이 없는지 확인한다.
6. 바꾼 용어표와, 판단이 필요해 남겨 둔 것을 보고한다.

## 참고 예시 (실제로 바꾼 것)
| 전 | 후 |
| --- | --- |
| 지금 할 일 | 처리할 업무 |
| 내가 판단할 일 | 판단 대기 |
| 내가 이어받을 일 | 인계받은 업무 |
| 다음 할 일 | 다음 조치 |
| 막힌 이유 | 막힘 사유 |
| 원래 요구사항 | 상위 요구사항 |
| 마지막 확인 뒤 바뀐 것 | 미확인 변경 |
| 지금 여기 | 현재 위치 |
| 현재 기준 / 이전 기준 | 현행 기준 / 종전 기준 |
| 설명만 있음 | 서술 근거 |
| 다시 시도 | 재시도 |
| 반영됐는지 확인 | 반영 여부 확인 |
| 다른 사람에게 넘김 | 다른 담당자에게 인계 |
| 되돌려 보냄 | 반려 |
| 아직 안 됨, 미검증, 배포 전 | 미실시 (하나로 통일) |

## 자주 생기는 실수
- 문장까지 명사로 줄여 "저장 실패. 재시도 요망."처럼 만드는 것. 문장은 "저장하지 못했습니다. 재시도해 주세요."로 둔다.
- 낱말만 바꾸고 조사를 확인하지 않는 것.
- 같은 뜻의 한자어를 화면마다 다르게 고르는 것(확인/점검/검토). 용어표에서 하나로 정한다.
- 사용자가 정한 상태 이름이나 고유 용어를 묻지 않고 바꾸는 것.
